# 🌐 Web Scraping Project – Companies Revenue Data

## 📌 Overview

This project demonstrates how to scrape company revenue data from a website using Python and convert it into a structured dataset. The extracted data is cleaned and stored in a CSV file for further analysis.

---

## 🚀 Features

* Extracts data from a website using web scraping
* Parses HTML using BeautifulSoup
* Stores data in a Pandas DataFrame
* Exports cleaned data to a CSV file

---

## 🛠️ Technologies Used

* Python
* Pandas
* Requests
* BeautifulSoup
* Jupyter Notebook

---

## 📊 Output

* Clean dataset containing company revenue information
* CSV file ready for analysis
